# Reliquias Braids no GitHub Pages

Esta pasta pode ser publicada como demonstracao no GitHub Pages.

## Publicacao

1. Crie um repositorio publico no GitHub, por exemplo `reliquias-braids`.
2. Envie `index.html`, `inicio.jpg`, `foto1.jpg`, `foto2.jpg`, `foto3.jpg`, `foto4.jpg` e `foto_roberta_site1.jpg`.
3. No repositorio, abra **Settings > Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch principal e a pasta `/root`.
6. Salve e aguarde o link ser gerado.

Nesta versao demonstrativa, o calendario mostra horarios de exemplo e o formulario abre o WhatsApp. O servidor, painel, reservas reais, notificacoes e Mercado Pago continuam funcionando apenas na versao Node.js local ou em uma hospedagem com servidor.
